# Тихие маршруты

Небольшой сайт-путеводитель на Astro: ищите места для поездки, фильтруйте маршруты по настроению и сохраняйте понравившиеся в избранное.

## Локальный запуск

```sh
npm ci
npm run dev
```

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и отправьте проект в ветку `main`.
2. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации.
3. После отправки изменений workflow автоматически соберёт сайт и опубликует его. Повторный запуск доступен во вкладке **Actions**.

Путь к сайту настраивается автоматически для адреса проекта (`owner.github.io/repository/`) и пользовательского сайта (`owner.github.io/`).
